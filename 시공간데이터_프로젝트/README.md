# 서울 지하철 시공간 이용 패턴 분석

서울시 노선/역/시간대별 지하철 승하차 인원 데이터를 이용한 시공간 데이터(spatiotemporal data) 분석 프로젝트입니다.

## 문제 정의

- 데이터: 서울철도 일별·시간대별 승하차 인원 (호선, 역, 시간대 단위)
- 목표: 노선·역·시간대(hour)별 이용객 패턴을 시각적으로 파악하고, 혼잡 시간대/구간을 식별

## 접근 방법

1. 승차·하차 인원을 합산해 `총이용객수` 산출
2. `호선 × 역 × hour` 단위로 그룹화 후 평균 이용객 수 집계
3. 노선별(예: 2호선) 시간대-역 히트맵으로 시공간 패턴 시각화
4. 한글 폰트(NanumFont) 설치 등 시각화 환경을 Colab 기준으로 구성

## 파일 구성

- `시공간데이터_분석.ipynb` — 데이터 로드, 집계, 히트맵 시각화 전체 파이프라인

## 배운 점

- 시간(hour)과 공간(호선·역)이라는 두 축을 동시에 다루는 데이터를 다차원 groupby와 히트맵으로 효과적으로 시각화하는 방법을 익힘
