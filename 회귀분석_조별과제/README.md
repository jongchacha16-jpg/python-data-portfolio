# 레드 와인 품질 회귀분석 (Wine Quality Regression)

레드 와인의 이화학적 특성(산도, 당도, 밀도 등)으로 품질(`quality`)을 설명/예측하는 회귀분석 팀 프로젝트입니다.

## 문제 정의

- 타겟: `quality` (와인 품질 점수)
- 설명변수 간 다중공선성(예: `density`와 `residual sugar`의 높은 상관관계) 처리가 핵심 이슈

## 접근 방법

1. 데이터 탐색 및 설명변수 간 상관관계 분석
2. 전체 설명변수를 포함한 기본 OLS 회귀모델 적합
3. 변수 변환 및 변수 선택(다중공선성이 높은 변수 정리)을 통한 모델 개선
4. 잔차 분포도(residual plot)로 회귀 가정(등분산성, 정규성) 검토
5. 화이트 와인, 레드 와인, 두 데이터 통합 케이스를 각각 비교 분석

## 파일 구성

- `Red_Wine(박찬종).ipynb` — 담당 분석 파트 (레드 와인, 변수 변환·선택·잔차 분석)
- `Red_wine(변수 변환,변수 선택,잔차 분포도).ipynb` — 변수 변환/선택 실험
- `wine.ipynb`, `residuals.ipynb` — 모델링 및 잔차 진단 실험
- `보고서 작성자료(wine).ipynb` — 팀 보고서용 정리 자료

## 배운 점

- 상관관계가 높은 설명변수를 그대로 회귀에 투입했을 때 발생하는 다중공선성 문제를 VIF/상관행렬로 진단하고 대응하는 경험
- 잔차 플롯을 통해 회귀 모델의 가정(선형성, 등분산성)을 점검하는 습관을 익힘
