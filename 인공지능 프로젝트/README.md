# 표정 데이터셋 기반 표정 분류 모델 (Emoji Autoencoder)

표정(이모지) 이미지 데이터셋을 이용해 표정을 분류하는 오토인코더 기반 모델을 시도한 프로젝트입니다.

## 문제 정의

- 목표: 이모지/표정 이미지 데이터를 이용한 표정 분류 모델 구축

## 진행 및 한계

이 프로젝트는 기한 내 목표를 완전히 달성하지 못했습니다. 원인을 정리하면:

- 기본 이모지 이미지를 변환해 학습 데이터로 쓰려 했으나, 변환 과정에서 이미지가 모두 흰 배경으로 손상되어 전처리에 실패
- 이모지 원본 이미지 자체가 기업 자산(라이선스 소유물)에 해당해, 자유롭게 사용 가능한 정제된 데이터셋을 구하기 어려웠음
- 위 데이터 확보 문제로 인해 기한 내 모델 학습까지 완료하지 못함

## 파일 구성

- `Emoji_Autoencoder.ipynb` — 데이터 전처리 시도 및 실패 원인 기록
- `emoji_df.csv`, `emoji-test.txt` — 수집/전처리 시도 데이터
- `emoji_testpage_screnshot.png` — 데이터 수집 과정 스크린샷

## 배운 점

- 이미지 데이터셋의 저작권/라이선스 제약이 실제 프로젝트 진행에 미치는 영향을 직접 경험
- 데이터 전처리 파이프라인의 중간 산출물을 눈으로 검증하지 않으면(예: 변환된 이미지 확인) 문제를 뒤늦게 발견할 수 있음을 확인
- 제약 조건 안에서 대안 데이터 소스를 탐색하는 것의 중요성을 체감
